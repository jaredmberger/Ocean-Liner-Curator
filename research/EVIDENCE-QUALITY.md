# Historical Research Agent: Evidence Quality Protocol

This is an editorial specification, not proof that the model independently verified every claim.

Each candidate finding should include a specific claim; comparison with existing guide content (new, already present, conflicting, unclear); vessel identity and era; a direct source URL; source institution and date when known; classification (contemporary primary document, archive catalog record, scholarly secondary, general secondary, derivative); source access status (actual source inspected, search snippet only, inaccessible); confidence rationale; contradictions; and next verification step.

Prioritize up to three substantial research leads over many weak observations. An archival catalog description is not equivalent to reading its original item. Multiple sites repeating one unsupported claim are not independent corroboration. If support is inadequate, recommend no change.

Dossiers and confidence assessments remain unverified model output. The source URLs have not been independently checked by code. No ship guide should be edited without editorial source review.

The existing research-ledger PR workflow continues to record investigations, not certified claims.
